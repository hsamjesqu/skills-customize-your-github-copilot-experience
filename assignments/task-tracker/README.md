# 📘 Assignment: Task Tracker

## 🎯 Objective

Build a simple task tracker using Python functions and reusable code. This assignment helps students practice breaking a program into smaller pieces, validating input, and organizing logic so it is easier to maintain.

## 📝 Tasks

### 🛠️ Create the Core Task Functions

#### Description
Design a program that lets a user add, view, and mark tasks as complete in a small task list.

#### Requirements
Completed program should:

- Store tasks in a list or dictionary structure
- Create a function to add a new task
- Create a function to display all tasks
- Create a function to mark a task as complete
- Validate task input so blank or invalid entries are handled safely
- Keep the program easy to read by separating logic into functions

### 🛠️ Add Task Management Features

#### Description
Expand the task tracker to support realistic behavior for managing work items.

#### Requirements
Completed program should:

- Allow the user to remove a task by ID or name
- Show task status such as complete or incomplete
- Prevent duplicate task names if that is part of the design
- Use simple, descriptive function names
- Return helpful messages when a task is not found

### 🛠️ Organize the Program

#### Description
Refactor the code so it is modular and easier to extend in the future.

#### Requirements
Completed program should:

- Split related logic into separate functions or modules
- Keep the main program focused on user interaction
- Use clear variable and function names
- Avoid repeating the same logic in multiple places
- Explain how the program is organized in a short summary
