# 📘 Assignment: Building REST APIs with FastAPI

## 🎯 Objective

Build a small REST API using the FastAPI framework and Python. This assignment introduces students to routing, request handling, JSON responses, and basic API design patterns.

## 📝 Tasks

### 🛠️ Create a Basic API

#### Description
Build a simple web API that exposes a few endpoints for managing a collection of items, such as books, tasks, or students.

#### Requirements
Completed program should:

- Use FastAPI to define at least two API routes
- Accept JSON data in request bodies for creating or updating items
- Return JSON responses from the API
- Support at least one GET endpoint to retrieve data
- Support at least one POST endpoint to add data
- Validate input using FastAPI request models or basic checks
- Include a simple response for invalid or missing data

### 🛠️ Add API Logic and Data Modeling

#### Description
Expand the API with a realistic data model and a few more operations so the service behaves like a small application backend.

#### Requirements
Completed program should:

- Use Python data structures or a lightweight in-memory store for application data
- Define clear item fields such as id, name, and description
- Support retrieving a single item by ID
- Support creating, updating, or deleting an item
- Return helpful status codes for successful and unsuccessful requests
- Keep the API code organized and readable

### 🛠️ Explore API Concepts

#### Description
Finish the assignment by testing the API and documenting the main routes and behaviors.

#### Requirements
Completed program should:

- Run the FastAPI app locally and verify endpoints in a browser or API client
- Use the FastAPI docs interface to inspect the available routes
- Describe what each endpoint does in a short summary
- Include clear examples of request and response payloads
- Explain how the API handles errors or invalid input
